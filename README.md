# NODAL — 3D website

A framework-free spatial studio site with real-time WebGL scenes.

## Pages

- `index.html` — the landing page: particle field, faceted core, orbital rings, drag-to-orbit.
- `work.html` — the work archive: animated wave-mesh terrain, filters and case-study drawer.
- `letters.html` — the Jason World page with red/green welcome text, 3D JASON letters scaled to 150%, animated shooting stars, and a generated dramatic soundtrack.
- `jason-theme.wav` — a 24-second cinematic audio loop generated by `tools/generate-theme.mjs`.

## Run locally

```bash
node server.mjs
```

Open `http://127.0.0.1:4173/letters.html` and press **Play dramatic score**.
